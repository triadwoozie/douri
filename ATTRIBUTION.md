# Third-Party UI & DSP Attributions

Dōri is released under the GNU General Public License v3.0 or later (`GPL-3.0-or-later`).
We gratefully acknowledge the following open-source projects and design inspirations:

- **Pro-Wave** (`https://github.com/fabox-os/Pro-Wave`) — Upstream pure-Rust DAW foundation (`GPL-3.0-or-later`).
- **Yuri Beats** (`https://github.com/yuribeats/prowave`) — DAW UI and workflow contributions (`GPL-3.0-or-later`).
- **SoundCraft** (`https://github.com/storytold/soundcraft`) — Reference DSP, graphics backend guards, and RT-safe logging patterns (`MIT / Apache-2.0`).
- **Transit** (`https://github.com/derekmwright/transit`) — Reference PipeWire-JACK detection and localhost control protocol patterns (`MIT / Apache-2.0`).
- **AudioKnobs** (`https://github.com/Megaemce/AudioKnobs`) by **Megaemce** — Moog-inspired scalloped and chicken-head rotary knob geometry and visual design (alongside its upstream design inspirations noted in its README: `aike/webaudiosynth`, `desandro/dial-knob`, and `knobshop.com`).
- **Phosphor Icons** (`https://phosphoricons.com`) by Helena Zhang & Tobias Fried (`MIT`).
